What this demo proves

The interface is intentionally simple; the depth is in the decision flow and traceability behind each response.

01 · ROUTE

Use the right retrieval path

Explicit identifiers go to SQLite lookup; general questions use semantic retrieval instead of treating every query the same.

02 · GROUND

Preserve supporting context

Top chunks are reranked and expanded to parent notes before generation, with note metadata carried into the Evidence Vault.

03 · VERIFY

Make quality inspectable

Answers expose their evidence and the full application supports RAGAS faithfulness and answer-relevancy evaluation.
